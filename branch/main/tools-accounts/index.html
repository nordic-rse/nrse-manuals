Tools and accounts

An overview of the tools and services Nordic-RSE uses, what we use them for, and how to get access.

Communication

Tool

Used for

Account / access

Zulip

Main community chat in the #nordic-rse channel, on the Zulip organization shared with CodeRefinery; meeting reminders and agendas; event-specific channels

Anyone can join. Board members get access to a private board channel.

E-mail: secretary@nordic-rse.org

Main contact address; all conference communication; CoC warning reports

Board members get their own firstname@nordic-rse.org address with delegated access to the secretary account.

Mailing list

Staying in touch with people who don’t use the chat; annual meeting reminders

Sign-up via a Google Form; E-mails are sent manually by the board.

Accounts to set up when joining

New organizing team members should get accounts on Zulip, GitHub and HackMD, and ask to be added to the Nordic-RSE GitHub organization and HackMD team (see onboarding.md). Board members additionally get the private Zulip channel, the HackMD board team, and a nordic-rse.org e-mail address (see board/onboarding.md).
