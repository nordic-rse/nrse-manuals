# Nordic-RSE community chat

The Nordic-RSE community lives in a Zulip chat shared with CodeRefinery: https://coderefinery.zulipchat.com

For the basics of using the chat, see the [CodeRefinery chat guide](https://coderefinery.github.io/manuals/chat/).

The main Nordic-RSE channel is called #nordic-rse. In addition, there are several activity planning channels, such as #nordic-rse-2027-org which is for planning the 2027 Nordic-RSE conference.
