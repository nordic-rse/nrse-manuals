# Timeline

The times mentioned here are an approximation.

See [av.md](av.md) for AV (audio/visual) setup and presenting logistics, and [tools-templates.md](tools-templates.md#social-media-posts) for which announcements to post when.

## ~Year before

- [ ] Find location
- [ ] Set dates
- [ ] Book rooms
- [ ] Build organizing team
- [ ] Send "save the date": newsletter, social media, chat

## ~10 months before

- [ ] Set roles for organizing team
- [ ] Create website
- [ ] Check about accommodation
- [ ] Check about catering options
- [ ] Decide on ticket price
- [ ] Sponsor outreach
- [ ] Start consistent meetings
- [ ] Think about keynote speakers
- [ ] Decide on conference topic
- [ ] Decide on possible contribution types, think venue and time
- [ ] Decide on deadlines, think catering, scheduling

## ~6 months before

- [ ] Set up registration
- [ ] Set up payment system
- [ ] Add practical info to the website: hotels, travel, sightseeing
- [ ] Open call for contributions
- [ ] Open registration
- [ ] Announce call for contributions and registration: newsletter, social media, chat

## ~3 months before

- [ ] Close call for contributions
- [ ] Send acceptance, instructions, confirmation
- [ ] Decide on session topics and build the schedule
- [ ] Reach out to volunteers (if needed) and onboard them

## ~1 month before

- [ ] Set up collection process for presentations (see [av.md](av.md#collecting-contributions-in-advance))
- [ ] Prepare something for community building
- [ ] Order nametags, think personalization
- [ ] Get speaker gifts
- [ ] Get organizer gifts
- [ ] Order goodies for participants / sticker table

## ~1-2 weeks before

- [ ] Send author instructions
- [ ] Close registration
- [ ] Confirm catering
- [ ] Send participant info
- [ ] Prepare intro/outro presentation
- [ ] Prepare feedback form

## Day before / conference days

- [ ] Set up and test AV (see [av.md](av.md))

## After the conference

- [ ] Send feedback form
- [ ] Write blogpost for website
- [ ] Prepare report to share with board
